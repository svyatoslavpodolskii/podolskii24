One UI 8 Watch / Wear OS 6, API 36+. Основа — **Watch Face Format v4** и

После выбора Podolskii24 удерживайте циферблат → **Настроить**.

| Фон | White / Ivory / Black | White |
| Периоды суток | None / Lines / Labels / Color | None |
| Границы периодов | Quarter / ShiftedBack1Hour | Quarter |
| Стиль разделителей суток | Micro / Radial / Full / Arc / Classic | Micro |
| Стиль стрелок — HandStyle | По стилю циферблата / 20 ручных вариантов | По стилю циферблата |
| Минутная дорожка — MinuteTrackStyle | None / TicksOnly / FiveMinuteLabels / SputnikRing / InstrumentRing | None |
| Минутная стрелка | Выключена / включена | Выключена |
| Дополнения №1–3 | Системный источник / пусто | Пусто |

Все группы независимы. Смена стиля, фона или границ не сбрасывает другие
значения. В сцене используются штатные `ListConfiguration`, `BooleanConfiguration`
и поддерживаемые WFF conditions; вложенных использований конфигураций нет.

**Classic** использует лёгкую шкалу, цифры через два часа и тонкую сужающуюся
стрелку. **Minimal** — простую 24-часовую шкалу, узкие цифры и гранёную Sword.
**Sputnik** — техническую шкалу со 144 делениями, собственную типографику и
ланцетную стрелку с белой вставкой и красным контуром. **Instrument** — акцентные основные
числа, 96 чистых делений и новый цельный приборный комплект стрелок.
Каждый стиль работает со всеми тремя фонами. Логотипы с референсов не копируются.

**Aviator** — дополнительный вариант с крупными геометрическими цифрами,
оранжевыми метками и вытянутыми приборными стрелками по предоставленному
авиационному референсу. Исходные четыре оформления сохранены. Шкала остаётся
24-часовой: 12 сверху, 18 справа, 24 снизу, 6 слева. Чужие надписи и имитация
хронографа не добавляются; работают прежние три системных дополнения.

## Оба пресета периодов

| Период | Quarter | ShiftedBack1Hour |
| --- | --- | --- |
| Ночь | 00:00–06:00 | 23:00–05:00 |
| Утро | 06:00–12:00 | 05:00–11:00 |
| День | 12:00–18:00 | 11:00–17:00 |
| Вечер | 18:00–24:00 | 17:00–23:00 |

**Quarter — полноценный основной вариант:** ровные четверти по 90°, границы
00/24, 06, 12, 18. Ночь снизу слева, утро сверху слева, день сверху справа,
вечер снизу справа. У ShiftedBack1Hour те же четыре периода сдвинуты на час
назад; границы 23, 05, 11, 17. Это фиксированные интервалы, а не расчёт солнца.
Оба пресета работают во всех стилях, фонах и режимах отображения.

- **None:** периоды и разделители скрыты, выбранный основной фон сохраняется.
- **Lines:** выбранные разделители, без цветных заливок и подписей.
- **Labels:** разделители и подписи УТРО / ДЕНЬ / ВЕЧЕР / НОЧЬ.
- **Color:** полноэкранные тональные сектора, подписи и выбранные разделители.

На White/Ivory утро светлое тёплое, день очень светлый, вечер серый, ночь
графитовая. На Black используются четыре различимых тёмных оттенка.
Цифры, деления и подписи адаптируются к яркости области.
На границе светлого и тёмного сектора WFF-маски точно разделяют даже один
символ на две контрастные части. Толстые обводки вокруг цифр не используются.
Геометрия масок совпадает с геометрией заливок.

## Пять стилей разделителей

| Стиль | Геометрия в координатах 432×432 |
| --- | --- |
| Micro | Короткие засечки в кольце радиусов 138–157; центр свободен |
| Radial | Линии от радиуса 42 до 158; не проходят через стрелочный центр |
| Full | Приглушённые линии от центра до внутреннего края числовой шкалы, радиус 158 |
| Arc | Четыре дуги на радиусе 122; каждая отступает на 3° от границ периода |
| Classic | Винтажные радиальные метки 119–157 с небольшими поперечными дугами |

Выбор действует в Lines, Labels и Color. В None скрыты все пять вариантов.
Full имеет меньшую непрозрачность, чтобы разделители уступали стрелкам.
В цветном режиме контраст разделителей также задаётся точными масками секторов.
Micro выбран по умолчанию; длинные линии сохранены как отдельные варианты.

## Шрифты, стрелки и дополнения

В APK включены Abel, Barlow Condensed Regular/SemiBold, Roboto Condensed и Michroma.
Превью используют те же файлы шрифтов. Лицензии и источники:
[docs/fonts/README.md](docs/fonts/README.md). Шкалы и текст остаются нативными
WFF-элементами. Маленькие прозрачные изображения стрелок создаются из точных
контуров инструментом `tools/assets.py`; вращение выполняет системный WFF,
а не программа на часах. Весь циферблат не заменяется растровой картинкой.

Три настоящих круглых `ComplicationSlot` расположены слева, справа и снизу.
Поддерживаются `SHORT_TEXT`, `RANGED_VALUE`, `MONOCHROMATIC_IMAGE`, `SMALL_IMAGE`,
`EMPTY`. Каждый тип имеет свою разметку. Данные поступают только от системных
поставщиков; доступные источники зависят от установленных приложений на часах.
Для диапазона рисуется фактический прогресс, текст поставщика либо число.

По умолчанию все три слота пустые. Выбор **Нет / Пусто** полностью убирает
изображение дополнения и его подложку. Заполненные слоты имеют небольшой
круглый фон для защиты текста от секторных линий. Они не перекрывают цифры
или подписи периодов. Как в обычных аналоговых часах, движущиеся стрелки
могут кратковременно проходить над дополнениями и подписями; тонкая минутная стрелка
не создаёт постоянного препятствия для текста.

## Always On Display

Отдельная чёрная сцена AOD содержит редкие приглушённые метки, числа через
два часа и тонкую 24-часовую стрелку. Сектора, разделители, дополнения и
минутная стрелка скрываются. Нет секундных обновлений или переходной анимации.
Маски цветных секторов и растровые стрелки в AOD не используются.
Защита AMOLED и фактический расход батареи требуют проверки на устройстве;
срок автономной работы без измерений не заявляется.

## Сборка

Нужны JDK 21, Android SDK Platform 36, build-tools 35.0.0 и Python 3.10+
для тестов. Gradle Wrapper 8.13 и AGP 8.13.1 зафиксированы.

```sh
sdkmanager "platforms;android-36" "build-tools;35.0.0" "platform-tools"
```

Задайте `ANDROID_HOME` или путь SDK в `local.properties`.
Для Windows-пути в properties экранируйте двоеточие: `sdk.dir=C\:/Android/Sdk`.
Из корня проекта в PowerShell:

```powershell
python -m unittest discover -s tools -p 'test_*.py' -v
.\gradlew.bat :watchface:exportDebugApk :watchface:lintDebug --no-daemon
python tools/verify_apk.py
```

В Linux/macOS: `chmod +x gradlew`, затем `./gradlew` с теми же задачами.
Официальный валидатор WFF запускается автоматически с аргументом версии **4**.
Описание его происхождения: [tools/VALIDATOR.md](tools/VALIDATOR.md).
Готовый подписанный файл: **`dist/Podolskii24-debug.apk`**.
R8 удаляет автоматически создаваемые R-классы; удаление ресурсов отключено,
поскольку WFF обращается к ним динамически. В APK не должно быть DEX/JAR/SO.

Для будущего выпуска доступны `:watchface:assembleRelease` и
`:watchface:bundleRelease`. Release нужно подписывать собственным ключом.

Перегенерация сцены и изображений нужна только при разработке:

```powershell
python -m pip install -r tools/requirements-preview.txt
python tools/generate.py
python tools/render.py
python tools/check_previews.py
python tools/check_hands.py
```

## Установка по Wi-Fi ADB

1. На Galaxy Watch 6 должна быть Wear OS 6 / API 36. Включите режим разработчика
   через сведения о версии ПО, затем беспроводную отладку.
2. Подключите компьютер и часы к одной сети. Откройте на часах сопряжение
   с новым устройством и используйте показанные **на ваших часах** адреса:

```text
adb pair WATCH_IP:PAIRING_PORT
adb connect WATCH_IP:DEBUG_PORT
adb devices
adb install -r dist/Podolskii24-debug.apk
```

Порт сопряжения отличается от порта подключения. Код вводится по запросу ADB.
3. Удерживайте текущий циферблат → добавить циферблат → **Podolskii24** → применить.
   Снова удерживайте → **Настроить**, чтобы выбрать стиль, фон, периоды, границы,
   разделители, минутную стрелку и поставщиков дополнений.
4. После установки беспроводную отладку можно выключить.

Application ID: `dev.twentyfour.watchface`. Версия 4.2 / versionCode 7.
Для обновления тем же локальным debug-ключом используется `adb install -r`.
Идентификаторы настроек версии 2.0 сохранены, добавлен HandStyle со значением
«По стилю циферблата». После обновления проверьте сохранённые значения в редакторе.
Отдельной иконки запуска приложения нет. `INSTALL_FAILED_OLDER_SDK` означает,
что система часов старее API 36. Wear OS 4/5 не поддерживаются.

## GitHub Actions и проверки

Поместите содержимое этой папки в корень GitHub-репозитория. Workflow
`.github/workflows/build.yml` запускается при push, pull request и вручную.
Он устанавливает API 36, запускает тесты, WFF Validator, Gradle, Lint,
проверяет отсутствие кода и подпись APK. В **Actions → Build Podolskii24 → Artifacts →
Podolskii24-debug** будет архив с APK.

Фактические локальные результаты — [docs/VALIDATION.md](docs/VALIDATION.md).
Удалённый запуск GitHub Actions не выполнялся. По согласованию подготовлены APK
и инструкция; реальная установка и проверка на часах в этой сессии не проводились.
