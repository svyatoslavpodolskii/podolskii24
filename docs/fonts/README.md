# Шрифты TwentyFour

Включены открытые шрифты из официального репозитория Google Fonts:

| Файлы в `res/font` | Источник | Назначение |
| --- | --- | --- |
| `abel.ttf` | [Abel](https://github.com/google/fonts/tree/main/ofl/abel) | Цифры Classic |
| `barlow_regular.ttf`, `barlow_semibold.ttf` | [Barlow Condensed](https://github.com/google/fonts/tree/main/ofl/barlowcondensed) | Цифры Minimal/Instrument, AOD |
| `roboto_condensed.ttf` | [Roboto Condensed](https://github.com/google/fonts/tree/main/ofl/robotocondensed) | Кириллица, Sputnik, данные дополнений |
| `michroma.ttf` | [Michroma](https://github.com/google/fonts/tree/main/ofl/michroma) | Крупные геометрические цифры нового Aviator |

У всех четырёх семейств SIL Open Font License 1.1. Полные лицензии находятся рядом
с этим файлом и включены в APK как `assets/font-licenses.txt`.
Файлы шрифтов не изменялись. Генератор превью использует те же TTF, что и WFF.
