# Podolskii24 5.0.1 — проверка загрузки

Версия 5.0 устанавливается, но пользователь сообщил об отказе добавления циферблата на Galaxy Watch 6. Лог устройства недоступен, причина на устройстве пока не установлена.

Обнаруженный дефект: XML внутри APK 5.0 занимает 13 088 523 байта при документированном пределе WFF 10 МБ.
В 5.0.1 удалены только отступы XML: теперь 8 275 345 байт. Полное дерево сцены совпадает с 5.0 после нормализации пробелов; графика и конфигурации не менялись.

Добавлены ограничения размера в генератор, Gradle, автоматические тесты и проверку упакованного APK.
21 автоматический тест прошёл. Подтверждение исправления запуска требует повторной проверки на часах.

Документация: https://developer.android.com/docs/quality-guidelines/wear-app-quality#source-file-size
