# Продолжение разработки Podolskii24 на другом ПК

Основной проект — этот репозиторий, ранее папка `!DEV/TwentyFour`.
Экспериментальная папка `Podolskii24` не заменяет его. APK — ресурсный WFF v4,
пакет `dev.twentyfour.watchface`, без Kotlin/Java-сервиса и своего рендерера.

## Подготовка

Нужны Git, JDK 21, Python 3.10+ и Android SDK. Gradle 8.13 скачает wrapper.
Установить SDK Platform 36, Build Tools 35.0.0 и platform-tools.
Удобнее установить их через Android Studio → SDK Manager.

```sh
git clone https://github.com/svyatoslavpodolskii/podolskii24.git
cd podolskii24
python -m venv .venv
```

Активировать окружение: Windows PowerShell — `.venv\Scripts\Activate.ps1`,
Linux/macOS — `source .venv/bin/activate`. Если политика PowerShell мешает,
можно вызывать `.venv\Scripts\python.exe` напрямую.

```sh
python -m pip install -r tools/requirements-preview.txt
```

Указать `ANDROID_HOME` и `JAVA_HOME` либо создать локальный `local.properties`
с `sdk.dir=...`. Файл локальных путей не коммитить.

## Обычный цикл

Из корня проекта:

```sh
python tools/generate.py
python -m unittest discover -s tools -p 'test_*.py' -v
```

Windows:

```powershell
.\gradlew.bat :watchface:exportDebugApk :watchface:exportReleaseApk :watchface:lintDebug
python tools/verify_apk.py dist/Podolskii24-debug.apk
```

Linux/macOS:

```sh
chmod +x gradlew
./gradlew :watchface:exportDebugApk :watchface:exportReleaseApk :watchface:lintDebug
python tools/verify_apk.py dist/Podolskii24-debug.apk
```

Готовые APK находятся в `dist/`. Они не хранятся в Git — публичные сборки
публикуются в GitHub Releases. CI также собирает проверочный debug-артефакт.

**Подпись:** существующие публичные APK подписаны локальным ключом автора.
Release сейчас использует тот же локальный Android debug key, чтобы сохранить
возможность обновления. На новом ПК Android создаст другой debug key: такой APK
не установится поверх опубликованного с прежней подписью. Для продолжения
публикации обновлений нужно отдельно и безопасно перенести прежний ключ и
сохранить сертификат. В Git и Issues ключи/пароли не загружать. Для отдельного
тестирования можно удалить установленную версию; её настройки будут потеряны.

## Где что находится

- `tools/generate.py` — механика 24 часов, исходные настройки и геометрия.
- `tools/static_geometry.py` — запекание статики, обрезка PNG, объединение
  одинаковых ветвей и выбор ресурсов для APK.
- `tools/runtime_scene.py` — общие слои суток, компактные дополнения,
  сохранение AOD в базовом слое, исключение выбранных пользователем стрелок.
- `tools/minute_palette.py` — независимый цвет внешней минутной дорожки.
- `tools/usability.py` — общий размер стрелок, порядок слоёв и подписи суток.
- `tools/render.py` — локальный QA-рендерер. Это **не** эмулятор Wear OS.
- `docs/hand-masters/`, `docs/scale-masters/` — собственные SVG-исходники.
- `tools/assets.py`, `hand_art.py`, `instrument_classic.py`, `classic_scale.py`
  — генераторы графики. Для обычной сборки их запускать не требуется:
  проверенные PNG уже в репозитории. Перегенерация может изменить контрольные
  суммы сглаживания; делать её отдельно при осознанном изменении графики.
- `watchface/src/main/res/raw/watchface.xml` — сгенерированный рабочий WFF.
- `docs/optimization/geometry-sources.json` — данные для обратного раскрытия
  дерева при проверках. В APK не включаются.
- `tools/test_runtime_scene.py`, `test_stability.py`, `test_minute_palette.py`
  проверяют именно рабочую сцену. Часть старых тестов проверяет восстановленную
  исходную геометрию; одного их прохождения недостаточно.

После изменения генератора коммитить также рабочий XML, strings.xml,
используемые новые PNG и manifest оптимизации. Не редактировать только XML:
следующий запуск генератора затрёт такие правки.

## Состояние 5.3 и что проверить дальше

Сохранены шесть дизайнов, три фона, обе границы суток, все режимы секторов,
пять разделителей, минутные дорожки и их цвет, общий размер стрелок,
отключение минутной стрелки и три дополнения.

По старому нумерованному листу 5.2 пользователь удалил №2, 5, 8, 9, 15, 16,
17, 19. Осталось 14 пунктов с автоматическим выбором. Needle сохранена внутри
автоматического Classic, но удалена как отдельный дублирующий пункт.
Старые мастера остаются для истории и тестов, неиспользуемые PNG в APK не идут.

Ранее на Galaxy Watch 6 / One UI 8 были OOM, перезапуски, долгий вход в
редактор и неработающий AOD. 5.3 уменьшает рабочее дерево и память графики,
исправляет приоритет числового значения дополнений и меняет построение AOD.
**Реальное устранение сбоев ещё не подтверждено на часах.**

Проверить на Wear OS 6: выбор циферблата, вход в редактор, повторные изменения
настроек, RANGED_VALUE стресс, переход в AOD и обратно, несколько часов работы.
Проверка подписи/сборки/XSD и локальные картинки не заменяют этот этап.
Точные RSS/PSS, CPU, батарея и время открытия редактора ещё не измерены.
Статический Memory Footprint Evaluator оценивает ресурсы, а не всю память
системного WFF-процесса.

Не возвращать полную растеризацию секторных масок без сравнения бюджета:
отвергнутый эксперимент увеличивал декодируемые PNG до 39,7 МБ.
Не добавлять свои фоновые службы и не переводить часовую стрелку на обычную
12-часовую механику. Публичные имена: Podolskii24, пакет сохранять прежним.

Следующие пожелания пользователя: довести готовые пресеты, отдельный зелёный
ночной режим. Они пока не реализованы; приоритет — стабильность 5.3 на часах.
