# TwentyFour 4.1 — проверка Bell & Ross Photo

Добавлен только отдельный `HandStyle=bellross_photo`. Автоматическое назначение
и существующие стили, фоны, секторы, дополнения, MinuteTrackStyle и формулы
времени сохранены. Версия APK 4.1, versionCode 6, API 36+, WFF v4.

## Источник и метод

Использована приложенная фотография `references/bellross-original.jpg`.
Контуры заданы в координатах снимка; общий центр — 511,494. Масштаб переноса
0,60, центр WFF — 216,216. Фотографические цвет и поверхность перенесены
аффинным преобразованием без перекрашивания и синтеза освещения.

Часовая, минутная с круглым противовесом и центральный узел — отдельные PNG.
Редактируемые SVG содержат контур и вложенную текстуру. Секундная стрелка
не добавлена: существующая функциональность часов не менялась.
Фотография ограничивает разрешение фактуры; это перенос со снимка, а не
заявление о наличии заводских CAD-исходников или попиксельном совпадении.

## Сохранность

- **60 существовавших PNG стрелок побайтно совпадают** с манифестом перед добавлением.
- Если удалить только новый ListOption и условия его графических слоёв,
  **всё остальное дерево WFF совпадает** с исходным перед добавлением.
- Сохранён `references/before-photo-watchface.xml` для воспроизводимой проверки.
- Проверка не требует внешних архивов: `tools/check_photo_hands.py` использует
  приложенные XML и `hands-before-photo.json`.

## Проверки

- **17 тестов passed**: математика времени для всех минут суток, точки вращения,
  условия, настройки, ресурсы, AOD, дополнения, обе геометрии суток.
- **25200 сочетаний** с независимым HandStyle; отдельно **1200 сочетаний**
  MinuteTrackStyle, включая выключенную минутную стрелку.
- **150 рендеров нового комплекта**: все пять шкал, три фона, все пять
  минутных дорожек, минутная стрелка включена/выключена; покрыты оба пресета
  и None/Color. Это проверка сочетаний, не полный декартов перебор всех настроек.
- Контрольные изображения 03:00, 08:11, 10:30, 18:00 используют настоящие
  неизменённые выражения WFF, а не подставленные углы.

Сравнительный лист `previews/bellross_photo_comparison.jpg` намеренно совмещает
углы с фотографией для проверки контуров. Углы изменены только в копии XML
в памяти генератора превью; хеш исходного файла после операции совпадает.
Реальная механика отдельно показана в `previews/bellross_photo_native_times.jpg`.

Результаты: `photo-hand-checks.json`. Проверки Instrument и MinuteTrackStyle,
выполненные перед добавлением нового варианта, описаны в `VALIDATION-4.0.md`.
Их ресурсы и графические слои сохранены; новых изменений в них нет.

## APK

Gradle запускает официальный валидатор с аргументом версии **4** перед сборкой.
`verify_apk.py` проверяет точное совпадение упакованного XML и исходника,
обоих новых комплектов PNG и центрального узла, наличие MinuteTrackStyle,
геометрию 96 делений и отсутствие DEX/JAR/CLASS/SO.

APK: `dist/TwentyFour-debug.apk`; контрольная сумма: `dist/SHA256SUMS.txt`.
Сборка завершилась успешно. Официальная проверка WFF v4 и проверка подписи
APK v2 пройдены. Android Lint: **0 ошибок, 167 предупреждений**; полный
список приложен. Проверка упакованных XML и всех новых PNG также пройдена.
Полный Lint: `android-lint.txt`. Превью — локальный рендер рабочего XML,
не скриншот устройства. Проверка на часах отложена по просьбе пользователя.
