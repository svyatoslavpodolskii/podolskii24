# Podolskii24 5.5

Оригинальный проект TwentyFour. WFF v4, `dev.twentyfour.watchface`, versionCode 16.
Работа выполнена в `S:\MAIN\!DEV\TwentyFour`.

## Изменения

- `AodMinute`: независимое включение минутной стрелки в AOD, по умолчанию выключено.
  Она может отображаться в AOD при выключенной минутной стрелке обычного режима.
  Используется тот же ресурс, угол и центр, отдельного набора изображений нет.
- `Seconds`: секундная стрелка с шагом в секунду, по умолчанию выключена.
  Единственный источник SECOND находится в её условной ветви. В AOD слой скрыт
  безусловно. При включении обычный режим обновляется каждую секунду; это
  естественно расходует больше энергии, чем режим без секунд.
- `DialTone`: исходный, графит, синий, хвойный оттенки. Настройка сохраняет
  светлоту White / Ivory / Black, чтобы не ломать существующий контраст.
  Для подложки цвета основания Bell & Ross выбрать Black + графит.
  Секторы суток остаются независимыми и сохраняют свои цвета.
- `HandColor`: исходная графика, белый с тёмным контуром, тёмный со светлым,
  оранжевый и зелёный с тёмным контуром. В плоских палитрах нет граней и
  цветных вставок; сохраняется выбранный силуэт, включая прозрачную прорезь.
  Высококачественный внешний альфа-контур используется повторно, добавлены
  только небольшие одноканальные по содержимому RGBA-маски внутреннего покрытия.
  Они общие для всех фонов и цветов; комплект PNG на каждый цвет не создаётся.
- Sputnik: убраны швы построения обводки кривых и повторное уменьшение
  Lanczos, создававшее светлый ореол. Убрана коричневая грань; сохранены
  тёмная оправа и молочная вставка. Собственные SVG остаются исходниками.
- Несколько прежних тонких минутных стрелок заменены замкнутыми клинками
  с ровной тонкой обводкой вместо трёх наложенных линий. Их исходники:
  `docs/hand-masters/minute-blades/`. Число вариантов меню осталось 14.
  Часовые Instrument Classic и собственные старые мастера не изменены.
- `ScaleInset`: исходный или широкий отступ Instrument Classic.
  По умолчанию внешний радиус увеличен с 195 до 209,625 логических пикселей,
  без изменения центра. Компактный профиль при минутной дорожке сохранён.
- `MinuteInset`: полный радиус или небольшой отступ внешней минутной дорожки.
- `ComplicationSize`: визуальные диаметры 56 / 62,72 / 70, область нажатия 96.
  По умолчанию средний. Центры 162/210, 270/210, 216/256; увеличенные круги
  не пересекаются между собой. Иконки и значение масштабируются вместе.
- `DigitalSize`: исходный / средний / крупный. По умолчанию средний,
  цифровое время под нижним дополнением, без широкой подложки.

## Оптимизация

Общие и Aviator-ветви стрелок объединены: различия масштабов теперь выражены
только преобразованиями соответствующих ресурсов. Для плоских палитр один
набор силуэтов обслуживает три фона. Простые проверки выбора заменены штатными
сценическими ListConfiguration. Повторные OR-условия общих слоёв суток
свёрнуты по точным декартовым комбинациям; добавлен тест таблицы истинности.
Сложные условия и геометрия не упрощаются эвристически.

После просьбы пользователя о структурной оптимизации добавлен отдельный проход
`scene_compaction.py`. Он меняет организацию сцены, сохраняя её изображение:

- Обычная шкала хранится один раз на дизайн, фон выбирает только цвет.
- Четыре секторные заливки параметризованы границами и палитрой, вместо
  отдельных одинаковых геометрий для комбинаций оформления.
- 90 повторений подписей суток заменены восемью объектами: два слоя по четыре
  подписи сохраняют прежний порядок относительно цветной и обычной шкалы.
  Сохранены исходные округления координат и коррекция при минутной дорожке.
- Удалены 24 копии шаблонов дополнений для фонов. На каждый слот и тип данных
  теперь один шаблон, без изменения содержимого и изображения провайдера.
- Убраны 30 полнодисковых масок, внутри которых уже находилась вся графика.
  Проверяется реальное покрытие альфа-канала каждого ресурса и максимальные
  размеры при всех настройках масштаба. Необходимые секторные маски сохранены.
- Объединены 36 одинаковых условных ветвей. Взаимная исключительность
  проверяется по конечным доменам настроек всего соседнего ряда: совпадения
  изображений недостаточно, если ветви могут рисоваться одновременно.

Этот проход не добавляет PNG, не меняет разрешение и не заменяет шрифты.
36 изображений 432×432 совпали с вариантом до прохода **попиксельно**.
Отдельно все 360 комбинаций дизайна, фона, границ, режима подписей и минутной
дорожки сохраняют четыре исходных подписи, координаты, повороты и цвета.

XML меньше на 50,0%, дерево — на 47,7%, число масок — на 48,8%. Все PNG вместе выросли на 1,64%
ради покрытия плоских палитр и улучшенного Sputnik. Прежние бюджеты 800 КБ /
8000 элементов / 19 МБ PNG не ослаблены. Более того, теперь генератор, Gradle
и проверка APK ограничивают XML 400 КБ и дерево 4500 элементами.
Статическая оценка выбранных ресурсов
уменьшилась, но это **не измерение полного RAM процесса**. Оценка AOD имеет
ограничения относительно условных ветвей и не заменяет измерение на устройстве.
Отчёт инструмента сохранён в `memory-5.5.json`.

## Проверки и ограничения

46 автоматических тестов (45 общим прогоном и новый полный тест координат
отдельным прогоном), WFF v4, release/debug и lintDebug — успешно.
Проверены условные секунды, независимые минуты AOD, контрастные пары плоских
палитр, размеры и отступы, прежние механизмы, центры и геометрия.
Проверка APK сравнивает упакованный XML и реальные ресурсы с исходниками;
нет DEX, служб и собственного рендерера. Сохранена прежняя подпись обновления.
Экспорт release больше не содержит жёстко записанную старую версию в имени.

Превью получены из итогового XML: `personalization-5.5.jpg`, `active-aod-5.5.jpg`,
`sizes-insets-5.5.jpg`, `hand-selection-numbered-5.5.jpg`, `watch-size-5.5.png`.
Последний файл имеет размер 432×432, соответствующий экрану Watch 6 40 мм.
Это локальные изображения, не скриншоты Samsung. Иконки QA условные;
в APK дополнения используют изображения реальных провайдеров.
