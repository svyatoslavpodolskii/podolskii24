# Podolskii24 5.5.1

Исправлена компоновка дополнений. Сохранены обе схемы: цифровое время снизу
(по умолчанию) и сверху. Выбор доступен в стандартной персонализации WFF.

Круги масштабируются относительно собственного центра. Значки и значения
центрированы общей вертикальной колонкой, убран двойной контур индикатора.
Нижний вариант ограничивает диаметры до 48/50/52 единиц, верхний — до
48/54/58. Цифровое время отделено от нижнего круга; в верхнем варианте
нижний круг опущен. Размеры указаны для проектной сетки 432×432.

Структурная оптимизация 5.5 сохранена. Новые PNG не добавлены; один параметр
Layout управляет координатами и размерами штатными Transform. В схеме теперь
20 пользовательских настроек. Изменения относятся к ресурсам реального APK.

Повторяемые локальные превью: `python tools/preview_layout.py`.
Проверки: `python -m unittest discover -s tools -p 'test_*.py' -v`,
WFF Validator v4, Gradle release/debug и lintDebug, проверка содержимого APK.
Результат на реальных часах и время открытия редактора здесь не измерены.
