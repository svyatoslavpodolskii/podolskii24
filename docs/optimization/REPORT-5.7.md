# Podolskii24 5.7 / versionCode 24

## Изменения

- «Размер и оформление времени»: три размера с четырьмя вариантами — без оформления, контур текста, рамка без заливки, заливка с рамкой. Прежние идентификаторы размеров сохранены для совместимости. В рецептах №11/12 выбрана рамка без заливки.
- «Размер и расстояние дополнений»: четыре размера, каждый с обычной и более широкой расстановкой. В двухкруговой компоновке диаметры 120/136/152/168 единиц сцены; широкая расстановка сдвигает каждый центр наружу на 8 единиц. В обычной трёхкруговой компоновке размеры меньше; нижний круг ограничен при включённой минутной дорожке, чтобы не пересекать время.
- У секторных тем приглушены поверхности дополнений. Яркость их текста, значков и шкал снижена общим alpha; изображения SMALL_IMAGE не перекрашиваются.
- Рамка даты усилена до 1.2 единицы, окно сдвинуто с (318,318) в (308,322). Для двухкругового расположения расширены маски соседних часовых подписей, чтобы большие круги не задевали цифры. Остальные компоновки сохраняют полную шкалу.
- По-прежнему 20 пользовательских настроек: оформление совмещено с размером времени, расстояние — с размером дополнений. Новых ключей и runtime PNG нет.

## Реализация и оптимизация

В WFF v4 TimeText использует ограниченный Font, который не поддерживает Outline. Поэтому цифровое время использует один PartText на каждую из двух контрастных ветвей, Template `%02d:%02d`, штатные источники HOUR_0_23 и MINUTE. Нет секундной зависимости и копий текста со смещением.

Повторяющееся выражение цвета поверхности заменено штатным Reference themeSurface на уже существующем видимом слое фона. Дополнительного объекта для вычисления, PNG или фоновой службы не добавлено. Контрастная рамка состоит из двух векторных округлённых прямоугольников; заливка отключается отдельно от рамки.

| Показатель | 5.6.3 | 5.7 |
|---|---:|---:|
| XML, байт | 468673 | 448603 |
| XML-элементы | 4423 | 4490 |
| Верхняя оценка декодированных runtime PNG, байт | 19208528 | 19208528 |
| Release APK, байт | 1156445 | 1158069 |

Количество элементов немного выросло из-за дополнительных вариантов оформления и масок. Уменьшение XML не является измерением экономии RAM или ускорения редактора. Бюджеты остаются 470000 байт XML / 4500 элементов / 19300000 байт PNG.

## Проверка

Полный прогон: 67 тестов прошли. После финального сдвига даты отдельно повторены тесты оформления и геометрии. WFF v4 Validator, exportReleaseApk, exportDebugApk, lintDebug и verify_apk для обеих сборок прошли. Проверка APK сопоставляет упакованный XML и изображения с исходными ресурсами. SHA-256 release: `5bc82280d9e94d7e52ba2ecc18695882a53a59c9cc114bc609329947337d0849`.

Проверены локальные листы всей коллекции, AOD, четыре оформления времени и восемь сочетаний размера/расстановки дополнений. Данные дополнений демонстрационные; реальную разметку текста конкретного провайдера необходимо проверить на устройстве.

Galaxy Watch и эмулятор недоступны. Реальные RAM, скорость редактора, расход батареи и работа провайдеров на устройстве не измерялись. APK предоставляется локально для проверки; новый GitHub Release пока не публикуется.
