# Podolskii24 5.7.2 / versionCode 26

## Цифровое время

Причина мелкого времени в подборке — принудительный компактный размер `c_plain`, а у Instrument Classic дополнительно был уменьшен диапазон масштабирования. Теперь размеры одинаково трактуются всеми дизайнами: номинально 17 / 22.95 / 28.05 единицы сцены. В подборке выбран крупный вариант без оформления; в секторных рецептах №10–12 — средний, чтобы сохранить зазор до нижнего дополнения.

На часах: «Размер и оформление времени» → «Крупное — без оформления». Средний и компактный варианты, рамки, заливки и контур текста сохранены. Увеличенный текст потребовал чуть уменьшить дополнительное кольцо разделителя Arc при включённом времени, чтобы рецепт №9 сохранял зазор.

## Симметрия трёх одинаковых кругов

По уточнению пользователя нужна радиальная симметрия относительно оси стрелок, а не равносторонний треугольник со смещением всей группы. В компоновке `trio`:

- Classic, Minimal, Sputnik, Instrument: центры (132,216), (300,216), (216,300). Каждый находится на расстоянии 84 от оси (216,216).
- Aviator: (140,216), (292,216), (216,292), расстояние 76. Это сохраняет зазор до его широких боковых цифр.
- Instrument Classic: (148,216), (284,216), (216,284), расстояние 68. Его крупные 12/24 требуют более компактной группы.
- Внутри каждого дизайна все три дополнения одного диаметра. Четыре размера: 72/80/88/96; для Instrument Classic и Aviator — 64/72/80/88.
- Все позиции фиксированы и не меняются при включении минутной дорожки. Тесты проверяют одинаковый радиус, зеркальность, одинаковые диаметры, отсутствие пересечений и попадание в собственные native slots для всех шести дизайнов.

**Вариант с маленьким нижним дополнением сохранён без перестановки его кругов.** Сохранены также два больших боковых круга с маленькой датой. Новый радиальный расчёт применяется только к `trio`.

## Цвета секторных дополнений

Убрана общая серо-зелёная подложка, которая не совпадала с секторами. Теперь поверхности используют цвета самой палитры периодов: утро для левого круга, день для правого, ночь для нижнего. В ShiftedBack1Hour правый круг находится уже в вечернем периоде и использует его оттенок.

В тёмных секторных темах передний план приглушён до #AAB4A8 перед существующим alpha. У светлых подложек тёмный текст; у нижнего ночного круга — светлый. В остальных темах цветовые наборы сохранены. SMALL_IMAGE провайдеров не перекрашиваются. Автоматический тест проверяет принадлежность поверхностей палитре и контраст текста не ниже 4.5 после alpha-композиции.
