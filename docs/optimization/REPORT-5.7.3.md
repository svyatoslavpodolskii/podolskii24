# Podolskii24 5.7.3 / versionCode 27

Исправлен цвет цифрового времени в обычных палитрах Instrument Classic и Aviator. Вместо постоянного белого используется общий ACCENT из `tools/design_palette.py`, с тем же приоритетом явного набора стрелок и оттенка темы, что и у часовой шкалы. Для Aviator сохранено исключение белого набора. Светлый фон по-прежнему использует тёмные цифры; секторный контраст и AOD сохраняют прежние правила.

В подборке №1 время оранжевое (#F08A35), №3 янтарное (#FFC027), №18 оранжевое (#F08A35). №2 остаётся белым. Новая проверка сверяет привязку настоящего WFF Font к общей палитре и цвета №1/2/3/16/18, а также нейтральные и секторные варианты.

Прошли 5 тестов коллекции и 8 тестов оформления/контраста/геометрии, WFF v4 Validator, Gradle release/debug, lintDebug и verify_apk обеих сборок. Полный набор тестов повторно не запускался для этой правки цвета; предыдущий полный прогон 5.7.2 описан в его отчёте.
