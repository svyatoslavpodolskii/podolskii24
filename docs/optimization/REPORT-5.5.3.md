# Podolskii24 5.5.3 — компоновка по дизайнам

Компактная нижняя компоновка сохранена только для Instrument Classic,
где крупные 12 / 6 / 18 / 24 ограничивают свободное место. Другие пять
дизайнов используют более свободную схему: центры дополнений (154,216),
(278,216), (216,282); цифровое время начинается на y=326.

У обычных дизайнов диаметры дополнений 48 / 56 / 64, масштаб цифрового
времени 1 / 1,2 / 1,45. У Instrument Classic сохранены безопасные размеры
5.5.2. Время сверху доступно во всех дизайнах. Центры масштабирования
по-прежнему совпадают с центрами кругов. Зоны выбора расширены под
максимальные размеры и смещения.

Изменения используют Transform существующих объектов. Новых PNG и новых
настроек нет. Декодированный объём ресурсов не вырос: 18 322 208 байт.
Стрелки, шкалы, сектора и фоны не менялись.

## Визуальная проверка

`python tools/preview_sizes.py` создаёт четыре листа всех шести дизайнов:
дополнения разных размеров при неизменном времени и время разных размеров
при неизменных дополнениях, отдельно для верхней и нижней компоновки.
Также создаются две матрицы 3×3 для Sputnik и Instrument Classic: сверху
вниз растут дополнения, слева направо — цифровое время.

Листы созданы из реального WFF XML, это локальные превью, не снимки с часов.
Проверены визуально все размеры дополнений снизу и обе матрицы 3×3.

WFF v4, Gradle release, lintDebug и проверка ресурсов внутри APK прошли.
Все 48 автоматических проверок пройдены: после исправления недостающего
параметра в тестовых данных повторно пройден весь набор персонализации.
Итоговый XML — 378 642 байта, 4 072 элемента, 20 настроек.
Скорость редактора и работа на Galaxy Watch этой версией не измерены.
