# TwentyFour 4.2 — Instrument Classic

Версия 4.2 / versionCode 7. WFF v4, API 36+, ресурсный APK без кода.
Фотографический прототип заменён собственными векторными исходниками.
Прежний ID пункта HandStyle сохранён, отображаемое название — Instrument Classic.

## Источники и готовые ресурсы

`tools/instrument_classic.py` создаёт девять SVG в
`docs/hand-masters/instrument-classic`: часовая, минутная, центральный узел
для каждого из White, Ivory, Black. Растеризатор читает именно эти SVG.
Разрешены только polygon/path/circle и плоские цвета. Нет image, ссылок,
текстур, фильтров, градиентов или встроенных фотографий.

Получены девять отдельных PNG `instrument_classic_{hour|minute|hub}_{background}`.
В каждой существующей WFF-ветви выбранного фона указаны буквальные имена
готовых ресурсов. Новые tintColor, динамическая перекраска и адаптивные
графические механизмы не добавлялись.

Минутная и её противовес — единый замкнутый контур с кубическими кривыми.
Порядок слоёв: часовая, опциональная минутная, перерисованный центральный узел.
Геометрический центр всех трёх — 216,216.

## Проверки

- **18 тестов passed**, включая математику времени для всех минут суток,
  центры вращения и условия выбора ресурсов.
- **25200 сочетаний** с HandStyle; отдельно **1200 сочетаний** MinuteTrackStyle.
- **150 рендеров Instrument Classic**: все пять шкал, три фона, пять минутных
  дорожек, минутная включена/выключена; охвачены оба пресета и None/Color.
- Для всех девяти мастеров растеризация проходит при принудительно
  запрещённом `PIL.Image.open`: фотография не может быть входом генерации.
- Пиксели PNG совпадают с повторной растеризацией SVG.
- Все девять PNG имеют по одному связному компоненту и свободные поля:
  нет оторванных фрагментов и обрезанных краёв.
- Для каждой части три фоновых PNG различаются: это отдельные готовые
  варианты ресурсов, а не перекрашиваемый общий bitmap.
- **60 PNG остальных стрелок побайтно неизменны**. Если исключить только
  перерабатываемый пункт и его слои, остальные узлы WFF совпадают с исходными.

Контрольные положения: 03:00, 10:30, 18:00; экспорт 432×432 и крупные виды
центрального узла. Отдельно проверены полный циферблат и стрелки без шкалы.
Центральная область этих двух рендеров совпадает попиксельно.

Отчёт: `instrument-classic-checks.json`. Превью:
`previews/instrument_classic_backgrounds.jpg`, `instrument_classic_hands.jpg`,
`instrument_classic_time_checks.jpg`; отдельные PNG имеют суффикс `_432`.

## APK

Перед сборкой запускается официальный валидатор с версией формата **4**.
`verify_apk.py` проверяет точное совпадение упакованного XML с исходником,
всех девяти новых PNG и их назначение в WFF. Старые пять фотографических
ресурсов должны отсутствовать в APK; их наличие считается ошибкой.

APK: `dist/TwentyFour-debug.apk`. SHA-256: `dist/SHA256SUMS.txt`.
Полный Android Lint: `android-lint.txt`.
Сборка завершена успешно; WFF v4 и подпись APK v2 проверены.
Android Lint: **0 ошибок, 169 предупреждений**. Проверка содержимого APK
подтвердила все девять новых PNG и отсутствие пяти фотографических ресурсов.
